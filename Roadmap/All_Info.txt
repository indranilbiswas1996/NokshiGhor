গুরুত্বপূর্ণ Business Rules:
1. একটি Business-এ একাধিক Owner থাকতে পারবেন।
2. Owner নিজের Profile edit করতে পারবেন।
3. Owner-কে কখনো permanently delete করা যাবে না।
4. Owner inactive করা যাবে, তবে তার আগের records ও audit history থাকবে।
5. Inactive Owner Business-এর কোনো operational কাজ করতে পারবেন না।
6. শেষ সক্রিয় Owner-কে inactive করা যাবে না—অন্য সক্রিয় Owner নিশ্চিত করতে হবে।
7. Owner-এর permission এবং Business-এর data isolation Backend ও Database উভয় জায়গায় enforce করতে হবে।

পরবর্তী Development
আমার প্রস্তাব, এবার Branch Management শুরু করা।

এর মধ্যে থাকবে:
- Owner একাধিক Branch তৈরি করতে পারবেন।
- Branch List ও Branch Details।
- Branch Edit — Branch delete নয়।
- Branch Admin ও Employee assignment-এর ভিত্তি তৈরি।
- প্রতিটি Branch-এর Business ownership নিশ্চিত করা।
একটি Business-এর একাধিক Branch থাকতে পারবে।
Owner নিজের Business-এর সব Branch দেখতে ও পরিচালনা করতে পারবেন।
Owner Branch তৈরি ও Edit করতে পারবেন, কিন্তু Delete করতে পারবেন না।
একটি Branch-এ একাধিক Branch Admin ও Employee থাকতে পারবেন।
Branch Admin শুধুমাত্র তাঁকে Assign করা Branch দেখতে পারবেন।
Employee-কে এক Branch থেকে অন্য Branch-এ Transfer করা যাবে।
Branch, Admin ও Owner-এর গুরুত্বপূর্ণ Record Hard Delete করা যাবে না।
Branch Assignment, Employee Transfer এবং Permission পরিবর্তনের Audit Log রাখতে হবে।
